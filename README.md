# Advocate Billing Cloud

A simple mobile-friendly Advocate Billing web app.

## Features
- Client and case/matter entry
- Professional fee + expenses
- GST calculation
- Invoice list
- Paid / unpaid tracking
- Dashboard totals
- Works in a browser without installing software

## GitHub upload
Upload `index.html` and `README.md` into your repository's `Billing` folder.

For a public GitHub Pages deployment:
1. Open repository **Settings** → **Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select `main` and folder `/ (root)` if these files are in the repository root.
4. If the files are inside `Billing`, either make `Billing` the site root via a separate Pages setup or move/copy `index.html` to the repository root.
5. Save and wait for GitHub Pages to publish.

Note: this starter stores data in the browser (localStorage). For multi-device/cloud database storage, connect it to Supabase or another backend.
